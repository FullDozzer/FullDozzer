# ИНК · Расписание

Telegram-бот расписания для всех групп и преподавателей колледжа. Python 3.11+, aiogram 3, aiohttp, SQLite, Pillow.

## Возможности

- 73 группы из `POST /2025/json/groups`; каталог периодически обновляется, а встроенный снимок используется при недоступности сайта.
- Выбор группы с фильтрами по курсу и форме обучения.
- Команды с основным и premium/collectible username: `/help@mellowagent`, `/date@mellowagent 10.11.2026` и другие.
- Расписание на сегодня, завтра и произвольную дату; поиск преподавателя по фамилии.
- Независимые уведомления для выбранной группы и для каждого преподавателя.
- PNG-карточки расписания и единые информационные карточки групп: форма обучения, бюджет/коммерция, база, курс, семестр, даты семестров.
- Постоянный кэш расписаний и изображений.
- Учёт завершённых пар и прогноз по прежней формуле для каждой группы отдельно.
- Платная неанонимная рассылка с предварительной модерацией.

## Кэш

`schedule_cache` хранит владельца (`group:ID` или `staff:ID`), дату, хэш содержимого, нормализованные занятия и путь к PNG.

1. Первый запрос скачивает расписание и создаёт изображение.
2. Повторный запрос читает SQLite и существующий PNG без HTTP и Pillow.
3. Монитор проверяет сегодня и завтра для всех групп, включая ожидающие первой публикации, а также подписанных преподавателей.
4. При изменении хэша старая картинка инвалидируется, данные заменяются, подписчики получают новую версию.
5. При ошибке сайта старая версия не затирается.

Файлы находятся в `DATA_DIR/images`, база — в `DATA_DIR/bot.db`. В Docker `DATA_DIR` должен быть постоянным volume. `MONITOR_CONCURRENCY` ограничивает число одновременных обращений к сайту.

## Учебные часы

При первом выборе группы запускается одноразовый backfill с 1 сентября. Состояние хранится в `study_jobs`, обработанные даты — в `lesson_backfill_days`. Разные группы считаются независимо.

Каждая подгруппа сохраняется со своим предметом. Параллельные подгруппы не удваивают общее время группы. Отменённые занятия не учитываются. Один академический час равен 40 минутам. Формула прогноза не изменена:

```text
X  = фактически завершённые минуты
De = учебные дни с 1 сентября до сегодня
Dr = оставшиеся учебные дни до 30 июня
R  = X × Dr / De
Y  = X + R
```

## Рассылка всему колледжу

Цена обычного сообщения — 50 ₽, рекламного — 150 ₽. Порядок:

1. Пользователь принимает правила и отправляет одно сообщение.
2. Выбирает обычную публикацию или рекламу.
3. Модератор видит автора и содержимое, одобряет или отклоняет заявку.
4. Только после одобрения пользователю выставляется счёт Telegram Payments.
5. После проверки валюты, суммы, payload и статуса платежа сообщение копируется пользователям бота с указанием имени и username автора.

Запрещены 18+, насилие, сливы и персональные данные, травля, дискриминация, мошенничество, вредоносные ссылки, спам и незаконная реклама. Анонимной публикации нет.

Для включения нужны:

```dotenv
PAYMENT_PROVIDER_TOKEN=токен_платёжного_провайдера
ADMIN_IDS=123456789,987654321
```

Без этих значений кнопка сообщает, что рассылка недоступна; счета не создаются.

## Premium

Дополнительные usernames для команд перечисляются через запятую без `@`:

```dotenv
BOT_USERNAME_ALIASES=mellowagent
```

Основной username бот получает через `getMe` автоматически. Упоминания других ботов не принимаются.

HTML-заголовки поддерживают `<tg-emoji>`. Укажите ID custom emoji из набора, доступного боту:

```dotenv
PREMIUM_EMOJI_ID=...
```

Если значение пустое, используется обычный строгий текст без декоративных emoji.

## Запуск

```bash
python -m venv .venv
.venv/bin/pip install -r requirements.txt
cp .env.example .env
.venv/bin/python bot.py
```

Или через Docker. Не храните `.env` в Git.

## Проверка

```bash
.venv/bin/python -m unittest discover -s tests -v
```

Тесты используют временную SQLite-базу и не обращаются к боевому токену.
